# Devpost thumbnail — emotional prompts (3:2)

**Goal:** Judges should *feel* who this is for—and see them using it—before they read a feature list.

**Hard rules (keep every prompt):**
- No identifiable faces in sharp focus (profile / over-shoulder / hands / soft blur OK)
- No gore, assault depiction, crying close-ups, or “trauma porn”
- Synthetic campus mood — dignity + courage, not spectacle
- Exact **3:2** (e.g. 3000×2000). Sharp title text.
- Palette: forest `#1a5c4a`, slate `#0b1220`, fog, brass `#c9a227` — **no purple neon**

**Global negative (append to all):**
```
sharp identifiable face, celebrity lookalike, gore, blood, violence, sexual content, crying extreme close-up, horror, stock smile selfie, crypto coins, purple neon, cyberpunk HUD, blurry text, misspelled words, watermark, logo salad, crowded collage
```

## Idea map — who needs it, when they use it

| Beat | Emotion | Visual |
|------|---------|--------|
| **1. The night** | Fear + isolation | Hostel dark, phone alone |
| **2. The trap** | Helplessness | Two doors, both wrong |
| **3. The decision** | Courage trembling | Thumb hovering over Ring |
| **4. The ring** | Relief starting | Silent file success, soft light |
| **5. The committee** | Care without exposure | Inbox, identity empty |
| **6. The morning** | Quiet dignity | Walk to class, phone put away |

Best Devpost cover: **Beat 3 or 4** (product in use + emotion). Runner-up: **Beat 1** (hook) with title.
